# Безопасность и границы применения

Это предварительная локальная программа. Учебные роли и переключение пользователей не являются корпоративной аутентификацией. Не размещайте API напрямую в интернете и не открывайте порт локального запуска во внешнюю сеть.

## Разделение кода и данных

Запускатель хранит рабочие данные, пользователей, ключи, вложения и журналы **за пределами Git-репозитория**. Не переносите их обратно в исходники. Не используйте `git add -A` для архивирования рабочей базы. Резервное копирование выполняется отдельно от публикации кода.

## Перед промышленным применением

- Настроить корпоративную аутентификацию, проверку полномочий и HTTPS.
- Проверить резервирование, восстановление, обновление и откат.
- Определить правила хранения документов, персональных данных и журналов.
- Проверить интеграционные команды на отдельном испытательном контуре.
- Пересмотреть модель хранения и конкурентного доступа под фактическую нагрузку.

Не публикуйте секреты или рабочие документы в Issues. Для сообщения о потенциальной уязвимости используйте приватное сообщение об уязвимости GitHub, **если этот канал включён**; иначе сначала запросите у владельца приватный канал без передачи технических секретов в публичном обсуждении.

Проверка очищенного снимка снижает риск, но не является гарантией отсутствия всех уязвимостей. Старые релизные файлы другого репозитория не входят в эту поставку.
