# Запуск, обновление и локальные данные

Сохраните `Start-ProcessNavigator.cmd` и запустите его. Он скачает сценарий PowerShell из этого публичного репозитория по HTTPS, затем получит код. Сценарий не делает коммитов и отправки данных. В полученной пользовательской копии дополнительно отключён адрес отправки Git; адрес получения обновлений остаётся рабочим.

## Каталоги

| Что | Каталог по умолчанию |
| --- | --- |
| Исходники | `%LOCALAPPDATA%\ProcessNavigatorCommunity\source` |
| Рабочие данные | `%LOCALAPPDATA%\ProcessNavigatorCommunity\runtime\Data` |
| Сервер и интерфейс | `%LOCALAPPDATA%\ProcessNavigatorCommunity\runtime\app` и `wwwroot` |
| Журналы запуска | `%LOCALAPPDATA%\ProcessNavigatorCommunity\logs` |

При первом запуске копируется учебный контур. При последующих запусках он **не копируется поверх рабочих данных**. Обновляются код и шаблоны Excel. Изменённые исходники не сбрасываются автоматически: скрипт остановится, чтобы не потерять ваши изменения.

## Перенос существующих данных

До первого запуска можно выполнить:

```powershell
.\Start-ProcessNavigator.ps1 -ImportFrom 'C:\Projects\process-navigator\backend\ProcessNavigator.Api\Data'
```

Копирование выполняется только в ещё не созданный каталог `runtime\Data`, исходная папка не меняется. Копии проверяются по SHA-256, затем подготовленный каталог становится рабочим. Если рабочие данные уже существуют, импорт останавливается без перезаписи. Не копируйте данные работающего сервера: сначала завершите его, чтобы получить согласованный снимок.

## Параметры

- `-SkipUpdate` — использовать уже полученный код без обновления Git; первоначальное клонирование всё равно требует доступного репозитория.
- `-PrepareOnly` — подготовить исходники и данные, но не собирать и не запускать сервер.
- `-Port 5082` — выбрать другой локальный порт.
- `-HomePath 'D:\Applications\ProcessNavigatorCommunity'` — выделенная папка приложения.

Обычный адрес — `http://127.0.0.1:5081`. В отличие от режима разработки, интерфейс обслуживает тот же сервер, поэтому второе окно Vite не нужно.

## Остановка

Сервер запускается скрыто. Для остановки сохраните рядом `Stop-ProcessNavigator.cmd` или выполните `Start-ProcessNavigator.ps1 -Stop`. Проверяются PID, время запуска и командная строка именно этой сессии. Чужой процесс или повторно использованный PID не завершается. Данные сохраняются. Перед обновлением сначала остановите свою сессию сервера.

Запускатель требует существующих Git, .NET SDK 9, Node.js 22.12+ и pnpm/Corepack. Он не устанавливает программы глобально и не требует прав администратора. Данные в публичный репозиторий не передаются.
