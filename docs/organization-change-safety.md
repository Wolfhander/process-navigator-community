# Изменение оргструктуры и дорожек процессов

Привязка дорожки хранит устойчивые идентификаторы юридического лица и подразделения. Отображаемое название (полное или сокращённое) выбирается для каждой дорожки отдельно. Сквозность процесса выводится из юридических лиц его дорожек.

В окне «Оргпривязки» сохраняются только дорожки открытого процесса. Сервер сверяет их с текущей BPMN-моделью: если состав дорожек успел измениться, требуется обновить процесс и повторить назначение. Изменения в других процессах и справочнике подразделений не перезаписываются.

В настройках оргструктуры нельзя удалить подразделение или юридическое лицо, на которое ссылаются дорожки. Рядом с подразделением перечислены затронутые процессы. Сначала переназначьте их дорожки, затем удалите узел. При переименовании подразделения привязка по ID остаётся действительной; уже опубликованные BPMN-версии сохраняют своё историческое название. Для обновления надписи в черновике откройте его «Оргпривязки» и сохраните повторно.

При одновременной работе администраторов сохранение устаревшей формы оргструктуры возвращает конфликт вместо тихой перезаписи. Закройте форму, загрузите актуальную структуру и повторите изменение.
