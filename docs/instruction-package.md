# Сквозная инструкция выбранных редакций

## Состав законченного пакета

- [x] Корень — точно открытая модель, без загрузки другой редакции.
- [x] Дочерняя редакция выбирается явно: действующая на момент сбора либо точный номер версии.
- [x] Все связанные уровни обходятся последовательно, с повторными включениями в разных ветвях и кэшем чтения на сбор.
- [x] Циклы, ошибки чтения, несоответствие ID/версии и черновик вместо действующей модели явно диагностируются.
- [x] Отмена/смена исходной модели не позволяет позднему результату подменить отчёт.
- [x] Выбор редакций изменён — скачивание недоступно до повторного сбора.
- [x] Неполный документ требует отдельного подтверждения и сохраняет замечания.
- [x] HTML включает манифест версий, все включённые элементы и переходы, инструкции/описания, входы/результаты, нормы, документы, каналы, материалы и основания.
- [x] Текст экранируется; ссылки и команды не исполняются. В файле задана ограничительная политика CSP.
- [x] Проверены циклы, повторные ссылки, выбор версии, границы, отмена, XSS-строки и превышение размера; раздел интерфейса загружается отдельно.

## Ограничения

40 включений, 40 запросов дочерних моделей, 200 ссылок, глубина 8 (включая корень), суммарно 10000 элементов и 20000 переходов. HTML — не более 8 млн символов; превышение отклоняет создание, а не обрезает файл. Пределы обхода превращаются в замечания неполноты. Пользовательские модели не изменяются.

Это документ выбранного среза, не исторически согласованный снимок всей иерархии и не исполняемый маршрут. Действующие дочерние версии могут отличаться от редакций на момент публикации корня; для воспроизводимости выбирайте точные номера и сохраняйте файл. Один выбор применяется к одному ID процесса во всех ветвях. Несколько разных версий одного ID в одном пакете пока не выбираются.

Указатели на дочерние модели не сшивают стрелки автоматически. Доступность файлов, назначения сотрудников, фактическое исполнение и корректность условий не подтверждаются. Структурированные исключения и требуемые статусы документов не добавлены этим пакетом.

## Демонстрация

1. Открыть корень демонстрационного контура уровней 0–4.
2. Открыть «Инструкция», раскрыть инструмент сквозной инструкции и собрать.
3. Проверить список путей и версий: повторные включения сохраняются отдельно.
4. Для дочерней модели указать номер из её истории. Скачивание блокируется до нового сбора.
5. Скачать HTML, открыть локально и проверить глубокий уровень разработки чертежа, исходные переходы и подписи.
6. Для проверки ошибки указать несуществующий номер в тестовой выборке: модель не меняется, появляется замечание; неполный файл доступен только после подтверждения.

Эти проверки не считаются выполненными на основании автоматических тестов.
