# Пакет: навигация и печать представлений одной редакции

## Законченный объём реализации

- [x] Одна панель «Схема / Обзор / Инструкция / Ответственность» с прямым переключением.
- [x] Одно активное представление; панель скрыта при BPMN-редактировании.
- [x] Самостоятельный полноразмерный обзор без карточек инструкции.
- [x] Адрес сохраняет представление, редакцию, выбранный элемент и цепочку раскрытия; обновление восстанавливает представление.
- [x] Переход к исходному элементу без смены редакции.
- [x] Печать/PDF раскрывает разделы; завершение/отмена и размонтирование восстанавливают прежнее состояние.
- [x] Печатные стили: без навигации и фильтров, одна колонка, перенос текста.
- [x] Проверки адресов, переключения и жизненного цикла печати; производственная сборка и контроль размера модулей.

## Отдельная визуальная приёмка

- [ ] Длинная инструкция и ответственность в предпросмотре Chrome/Edge: все страницы, поля, отсутствие обрезания.
- [ ] Узкий экран и увеличенный шрифт; прямые адреса действующей/черновой/архивной редакции.

Реализация перечисленного объёма закончена; браузерная визуальная приёмка не подменяется модульными тестами.

## Границы

Печатается текущая выборка с явными пределами показа, не весь фонд. Графическое укрупнение, сквозные дочерние редакции, печать графической композиции, история браузера всех разделов, исторические справочники и структурированные исключения остаются в исходных пунктах 28, 77, 98–100. Завершение этого пакета не закрывает их автоматически.

## Демонстрация

1. Открыть демо-модель → «Обзор», раскрыть дорожку/элемент, перейти к нему на схему; сверить редакцию.
2. Выбрать «Инструкция», скопировать адрес и обновить страницу — открывается та же инструкция.
3. Переключиться в «Ответственность» → «Печать / PDF», проверить раскрытые разделы.
4. Отменить печать — ранее свёрнутые разделы снова свёрнуты.

Для точных проверок состояния использованы детерминированные тесты, без LLM: подготовка и проверка делегирования здесь дороже самого алгоритма.
