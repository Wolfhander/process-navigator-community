# Process Navigator 0.2.0-preview.2

Предварительная версия для локальной работы с существующими BPMN-процессами. Это не готовая промышленная интеграция с 1С.

## Что изменилось

- Появилась главная страница с переходами к карте, каталогу, общей проверке процессов, аналитике и настройкам.
- Каталог позволяет искать, сортировать, просматривать иерархию и удалять модель с подтверждением.
- Поддерживаются паспорта и уровни детализации 0–20, переход от задачи к детальному процессу и обратно.
- Общая проверка каталога отдельно анализирует действующие редакции, черновики и нечитаемые файлы. Из замечания можно перейти к конкретному месту схемы.
- Расширены оргструктура, привязки дорожек, массовое распределение по направлениям и полноразмерная аналитика портфеля.
- Встроенная справка стала пошаговым руководством пользователя; README и письменный мануал обновлены.

## Автономный Windows-пакет

Скачайте оба файла из Assets: `ProcessNavigator-0.2.0-preview.2-win-x64-offline.zip` и одноимённый `.sha256`. Для запуска без установки распакуйте ZIP в папку с правом записи и запустите `Start-ProcessNavigator.cmd`. Доступ в Интернет и установка Node.js или .NET Runtime на принимающем компьютере не нужны. Внутри архива находятся `INSTALLATION.md` и `USER-MANUAL.md`; [инструкция по автономной поставке](https://github.com/Wolfhander/process-navigator-community/blob/main/docs/offline-deployment.md) также доступна в репозитории.

Перед заменой работающей копии сохраните её каталог `app/Data`. Данные пользователя из старой версии не следует заменять демонстрационными файлами нового архива.

## Известные ограничения

Единый реестр документов и проверенный граф межпроцессных зависимостей ещё разрабатываются. Прямой и обратный калькулятор сроков в этот выпуск не входят. Реальное подключение к 1С и промышленная аутентификация требуют отдельного внедрения и проверки ИТ-службой.
