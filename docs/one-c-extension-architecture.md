# Размещение Process Navigator в контуре 1С

## Решение

Целевой вариант — **расширение-оболочка для 1С:ERP + внутреннее веб-ядро**.
Для пользователя Process Navigator является разделом ERP и открывается внутри общей
формы 1С. Технически интерактивный BPMN Canvas обслуживается внутренним приложением,
а расширение отвечает за единый вход, пользовательский контекст и безопасный вызов
команд прикладных решений.

Полная перепись существующего приложения на встроенном языке 1С нецелесообразна:
она продублирует BPMN-редактор, Canvas и веб-интерфейс, усложнит тестирование и всё
равно потребует HTML/JavaScript для качественного редактирования диаграмм.

## Почему это остаётся расширением 1С

- пользователь запускает навигатор из подсистемы ERP;
- типовая конфигурация не снимается с поддержки;
- права и текущий пользователь поступают из 1С;
- карточки, списки и команды ERP открываются нативно;
- доступ в Интернет не требуется: расширение и веб-ядро находятся в локальной сети.

## Системы

| Система | Роль | Предпочтительное подключение |
|---|---|---|
| 1С:ERP УП 2 | основное рабочее место и факты процесса | расширение и HTTP-сервис |
| 1С:PLM | изделия, КТД, версии и спецификации | штатный контур PLM/ERP и адаптер команд |
| 1С:ЗУП | сотрудники, должности, кадровые назначения | регламентированный обмен либо HTTP/OData |
| 1С:ERP.УХ / MDM | эталонная НСИ и холдинговые объекты | существующий интеграционный контур + API |
| КОМПАС-3D | 3D-модели и конструкторский состав | через штатную синхронизацию 1С:PLM |

## Этапы поставки

1. Демонстрация приложения в HTML-поле формы ERP.
2. Подписанный билет единого входа и сопоставление пользователей.
3. HTTP-сервис расширения с белым списком безопасных команд.
4. Адаптеры метаданных ERP, PLM, ЗУП и MDM без жёстких ссылок в BPMN.
5. Установочный `.cfe`, проверенный на точных релизах платформы и конфигураций заказчика.

## Важное ограничение

Файл `.cfe` нельзя корректно завершить до фиксации точных релизов платформы,
1С:ERP, расширения 1С:PLM и состава применяемых библиотек. До этого момента исходный
каркас служит контрактом и полигоном, но не заявляется как готовая промышленная поставка.
