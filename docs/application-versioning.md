# Версии самой программы

Страница «Настройки → Версии программы» показывает номер текущей сборки и журнал изменений приложения. Она не относится к версиям отдельных BPMN-процессов: их история открывается на странице процесса.

Единственный список пользовательских изменений находится в `frontend/process-navigator-ui/src/release-history.json`. Первая запись описывает текущую сборку и должна совпадать с версией в `frontend/process-navigator-ui/package.json` и `backend/ProcessNavigator.Api/ProcessNavigator.Api.csproj`. Автоматическая проверка этого правила находится в `frontend/process-navigator-ui/tests/releaseHistory.test.mjs`.

Для следующей версии разработчик:

1. Меняет номер в пакетах интерфейса и сервера.
2. Добавляет новую первую запись в журнал: отдельно добавлено, изменено, исправлено и убрано. Неподтверждённые изменения не записывает.
3. Оставляет `date: null` до публикации; после выпуска указывает дату в формате `YYYY-MM-DD` и соответствующий этап.
4. Собирает интерфейс и сервер, запускает тесты журнала изменений.
5. Публикует тег только после проверки версии; страница не создаёт тег и не обновляет программу автоматически.

Тег `v0.2.0-preview.2` соответствует следующей предварительной поставке после `v0.2.0-preview.1`. Перед каждым последующим выпуском сверяйте фактический список GitHub Releases с журналом изменений программы.
