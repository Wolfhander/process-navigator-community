# Тепловая карта — приёмка пункта 71

18 октября 2026. Контрольные данные `master-data/heatmap/control.json` синтетические и приняты как рабочий контрольный пример. Это не сведения предприятия.

Итог: 331 серверная и 241 клиентская проверка прошли; сервер и интерфейс собраны без предупреждений. HTTP-проверка сверила полные показатели и подтвердила 403 для исполнителя и неизвестного профиля. Фактический CSV из браузера содержит две строки выбранной организации и явное «Нет данных», без чужих подразделений.

Проверены участие без повторного счёта дорожек, отдельное владение, задачи, передачи через шлюзы, исключение передач между дорожками одного подразделения и фактические просрочки по ID шага. Одноимённые подразделения и одинаковый ID подразделения разных юридических лиц не смешиваются. Привязки с конфликтами, отсутствующие владельцы и неизвестные фактические шаги не распределяются наугад.

В настоящем мастер-каталоге: шесть подразделений, три участвующих, семь задач и пять назначенных владельцев моделей. Экземпляров нет — все фактические оценки просрочек отсутствуют, а не равны нулю. Отдельный контроль с двумя экземплярами проверяет реальные положительные значения и наблюдаемый ноль.

В браузере проверены шесть строк, фильтр организации А (две строки), расшифровка моделей и открытие схемы «Заказ на изделие». Скачан CSV этого фильтра. Серверный доступ ограничен существующим правом просмотра аналитики. Оформление проверено на текущем размере окна; при узком окне таблица имеет собственную горизонтальную прокрутку.

Карта отражает структуру и признаки задержек, не загрузку сотрудников и не доказанную причину узкого места. Подсчёт ведётся по отдельным моделям, без размножения по вхождениям детализации. Новый endpoint не меняет формат сохранённой истории портфеля. Релиз 0.2.0-preview.66-dev не перевыпускается; пакет 0.2.0-preview.67-dev публикуется только в main.
