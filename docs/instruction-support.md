# Подготовка к работе по открытой модели

## Реализованный сценарий

- [x] Явная проверка по кнопке, без автоматических сетевых запросов при открытии.
- [x] Текущие назначения дорожки отдельно от персонального назначения выбранного экземпляра.
- [x] Экземпляр другого процесса/версии не используется; для черновика и архива App не передаёт текущий экземпляр.
- [x] Неизвестные/неактивные сотрудники и недоступные назначения не считаются отсутствием ответственности.
- [x] Точные версии artifact: проверяются HEAD, с правами текущего профиля, без кеша и без следования перенаправлениям.
- [x] Внешние ссылки и неуказанные версии не подменяются догадками и не запрашиваются.
- [x] Различаются 200, 404, 401/403, другие ответы и сетевые ошибки.
- [x] Три параллельных проверки, 200 уникальных запросов, дедупликация по ссылке/версии.
- [x] Отмена и смена модели защищают от позднего результата.
- [x] При ошибке назначений успешные результаты материалов остаются доступными и наоборот.
- [x] Поиск, страницы, время проверки и явная неполнота печатной выборки.

## Границы достоверности

HEAD подтверждает доступность точной версии сейчас, не проверяет содержание, соответствие регламенту или состояние каждого физического документа. Права могут измениться сразу после проверки.
Назначения — текущий справочник, даже если модель архивная; факт исполнения ими не подтверждается. На системном шаге сотрудник не объявляется исполнителем автоматической операции.
Персональное назначение показывается только из явно выбранного совпадающего экземпляра. Назначить или переназначить сотрудника следует в существующем интерфейсе выполнения, не здесь.
Сквозной HTML остаётся документом выбранных моделей: текущие проверки и персональные данные в него не переносятся.

Предел исходников: 5000 элементов и 20000 упоминаний материалов; превышение отклоняет проверку с сообщением. На странице 100 действий, на шаге до 50 материалов, с предупреждением об усечении. Внешние URL, file: и сетевые пути не проверяются.

## Проверка

Детерминированные тесты покрывают статусы, права в запросе, выбор версии, отсутствие внешних запросов, отмену, частичные ошибки, лимиты и разделение назначений. На изолированном API с синтетическим файлом проверено: HEAD 200 без тела, GET с телом, HEAD отсутствующей версии 404. Обработчик GET/HEAD и проверка View общие.
Визуальная/предметная приёмка в браузере не заменяется этими тестами и остаётся в 100.8.
