| Репозиторий документов | Аналитик, владелец | Готово | Версии актуальных инструкций и шаблонов |

| Назначения на дорожки | Владелец, администратор | Готово | Связь процессной роли с реальными сотрудниками |

| Аналитика пригодности каталога | Аналитик, руководитель | Готово | Нормативы, разрывы данных, передачи, системы, подразделения и уровни декомпозиции |
| Табличный обмен процессами | Аналитик, администратор | Готово | XLSX-шаблон, предварительная проверка, сравнение, выборочная загрузка, обратная выгрузка и журнал операций |

| Межпроцессный граф зависимостей | Все | Готово | Связи процессов через структурированные входы и выходы с обнаружением отсутствующих и неоднозначных источников |
| Рабочая цепочка этапа | Все | Готово | Источники входов, получатели выходов, замечания реестра и переход к связанному шагу непосредственно из карточки задачи |
| Калькулятор сроков | Все | Готово | Прямой и обратный расчёт, календарь, критический путь, резерв, контрольные даты, сценарии и объяснимая неопределённость |
| Командный адаптер | Исполнитель | Готово | Проверка, выполнение и аудит настроенных действий |

| Глобальный поиск | Все | Готово | Поиск по процессам, элементам, материалам и действиям |
| Обсуждения элементов | Все участники | Готово | Рабочие комментарии в контексте шага |

| Организационный профиль сотрудника | Администратор | Готово | Юридическое лицо, подразделение и должность пользователя с рекомендациями при назначении |
| Матрица ответственности процесса | Все | Готово | Сводка дорожек, подразделений, руководящих должностей и назначенных сотрудников с контролем незаполненных связей |
