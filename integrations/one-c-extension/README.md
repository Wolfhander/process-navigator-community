# Process Navigator: расширение-оболочка для 1С

Этот каталог содержит исходный каркас интеграционного расширения. Он не является
готовым файлом `.cfe`: метаданные расширения нужно создать в Конфигураторе или EDT,
после чего перенести модули из `src/` в одноимённые объекты.

## Целевая схема

1. Пользователь открывает общую форму `PN_НавигаторПроцессов` в 1С:ERP.
2. Поле HTML-документа показывает адрес внутреннего Process Navigator с параметром
   `host=1c` и контекстом информационной базы.
3. Расширение публикует HTTP-сервис `PN_API` для проверки доступности и выполнения
   белого списка команд.
4. Process Navigator хранит BPMN, контекст, версии и аналитику; 1С хранит свои
   документы, НСИ, пользователей и факты хозяйственной деятельности.

## Объекты расширения

- общая подсистема `PN_ProcessNavigator`;
- общая команда `PN_ОткрытьНавигатор`;
- общая форма `PN_НавигаторПроцессов` с полем HTML-документа `Навигатор`;
- общий модуль `PN_КлиентИнтеграции` (клиент, экспорт);
- общий модуль `PN_СерверИнтеграции` (сервер, экспорт);
- HTTP-сервис `PN_API` с шаблонами `/health` и `/command`;
- константы `PN_АдресСервера`, `PN_РазрешитьКоманды`.

## Демонстрационный запуск внутри HTML-поля

Для проверки режима размещения достаточно открыть:

`http://process-navigator.local/?host=1c&product=1С%3AERP&infobase=ERP`

Параметр `userId` в демонстрации может указывать идентификатор локального профиля.
В промышленной версии он будет заменён короткоживущим подписанным билетом, поэтому
идентификатор пользователя нельзя будет подменить в адресной строке.

## Границы адаптеров

- ERP: документы производства, закупок, продаж, склада и финансов;
- PLM: изделия, версии, КТД и ресурсные спецификации;
- ЗУП: сотрудники, должности и кадровые назначения;
- ERP.УХ/MDM: мастер-данные и холдинговые объекты;
- КОМПАС-3D: через штатную интеграцию 1С:PLM, без второго CAD-коннектора.
