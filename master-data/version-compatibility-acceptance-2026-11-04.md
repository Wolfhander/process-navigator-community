# Приёмка шага 85: версия и совместимость

- Текущая сборка: запись, frontend и API используют один номер.
- Проверенные категории в журнале: неизменный формат (.96), необязательные поля (.93, .40, .37), отдельная ручная операция (.18).
- Синтетическая проверка .93 опирается на `explicit-channel-acceptance-2026-11-04.md`: старая запись без ID читается, новая привязка проходит Excel-предпросмотр. Это не проверка записи новой схемы старой сборкой.
- Контроль страницы: сводка с переходами к существующим карточкам, отдельные поля обновления и отката, предупреждение для неописанных версий. Навигация не меняет адрес приложения и не вызывает API.
- Операция сброса в .18 не выполняется: запись объясняет предыдущую ручную команду, а не предлагает повторять её.
- Детерминированные проверки журнала и разметки не требуют Local AI Worker.
