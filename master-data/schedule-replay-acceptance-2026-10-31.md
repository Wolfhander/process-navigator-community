# Приёмка воспроизводимости расчётов — 31 октября 2026

Пункт 63. Два запроса в schedule-replay-fixture.json используют согласованный вымышленный демо-контур: прямой и обратный расчёт, часовой сдвиг, задержка передачи и коэффициент длительности. Файлы мастер-контура считаются рабочими входными данными.

## Результат

Серверный архив различает:

- сверку актуальности по текущему каталогу/реестру;
- повторение по замороженным источникам, без чтения текущих моделей и реестра;
- открытие сохранённого результата, которое не подменяет исторические даты текущими.

Повторение использует тот же расчётный код, но отдельный источник данных. Проверяется весь результат, включая источники, параметры, достоверность, замечания, нормы, даты и состав цепочки; исключается только время захвата. Неизвестный алгоритм и неполная цепочка не достраиваются из текущих файлов. Исходы Reproduced / Different / Unavailable не смешиваются.

Поддерживается явно указанный алгоритм текущей поставки, не исторический исполняемый файл. Совпадение — самопроверка воспроизводимости, не подпись и не доказательство достоверности исходных бизнес-данных. Локальный импортированный JSON не становится серверно подтверждённым автоматически.

При открытии серверного снимка прошлый результат показывается первым, затем автоматически выполняется отдельная проверка актуальности. Новый расчёт применяется только явно. Ошибка сети сохраняет прошлый результат и обозначает неустановленную актуальность. Операции сериализованы, ответы после размонтирования профиля не применяются. Повторение запускается отдельной кнопкой, не фоновым опросом всех архивов.
