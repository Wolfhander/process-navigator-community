# Сводная карта границ — приёмка 30 октября 2026

Исходники: неизменённый мастер-набор v1, пять моделей уровней 0–4 с пятью вызовами детализации. Испытания выполняются в отдельной копии Data; основной демонстрационный контур не изменяется.

Команда для изолированного сервера на 127.0.0.1:5087: `node tools/verify-decomposition-boundaries-http.mjs http://127.0.0.1:5087`. Скрипт требует ровно пять эталонных ID, создаёт черновики md-order и md-engineering, затем меняет только одноразовый тестовый черновик в artifacts/boundary-acceptance-20261030. Для повтора нужна свежая копия набора.

Проверены:

- Реальный API: версии 1.0 и тип действующей редакции с обеих сторон; после создания черновиков — версия 1.1 и правильные флаги источника/получателя.
- Разные уровни паспортов в тестовых черновиках: 7 и 8 вместо опубликованных 0 и 1. В границах показаны уровни именно сравниваемых редакций; у исполнителя сохраняются 0 и 1.
- Исполнитель продолжает получать опубликованные связи, без новой ошибки из закрытого ему черновика.
- Намеренно потерянная модель md-missing видна отдельным состоянием, без ссылки на несуществующий процесс.
- Браузер: общий список пяти связей, фильтр потерянных (одна из пяти), поиск по ID, открытие исходного task-2 именно в черновике md-order.
- Пустая поисковая выборка показана явно, обновление карты получает данные повторно.
- Фактически скачанный CSV содержит только выбранную потерянную связь, версии и типы редакций.
- Автотесты: состояния, противоречивые признаки ответа, поиск по диагностике и ID, пустая выборка, 203 независимых вызова, полный CSV, экранирование формул/кавычек, ссылки с особыми символами, HTML-экранирование и постраничность по 50 карточек.

Ограничения: структурные проверки не доказывают корректность условий ветвей и фактическую готовность документов. Архивы не сравниваются. Версии показаны на момент загрузки; переход открывает текущую редакцию выбранного типа. Ошибка загрузки всей карты не выдаётся за успешную пустую проверку.

Для этого пакета Local AI Worker не вызывался: проверки детерминированы и выполняются штатными API/тестами; проверка его сервера обнаружила, что Ollama не запущен. Запуск модели для этой задачи не требовался.
