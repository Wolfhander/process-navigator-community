# Приёмка аналитики систем (70)

- Контрольный маршрут из `transfers/process.json`: работа в PLM, общий выход «drawing», системный вход в ERP. В `TransferAnalyticsChecks` проверяются три явных способа, точный ID документа, система приёмника и путь.
- Противоположные примеры: другой ID, тот же системный контур, отметка вне точного системного входа. Структурные передачи без способа и действия вне системы проверяются отдельно.
- В `MasterDataChecks` временная копия контура получает вход с повторным вводом. XLSX содержит значение в колонке L, предварительный просмотр принимает выгрузку. Старые книги сохраняют совместимое значение по ID шага и канала.
- Это описание регламента, а не фактическое выполнение или запуск обмена. Для связей через вызовы структурные признаки остаются доступными без автоматического переноса регламентных отметок между моделями.
