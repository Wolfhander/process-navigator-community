## Принято

- Пункты исходного описания имеют стабильный ID и отдельный снимок в реестре. Ранее принятый перенос элементов/порядка/проверки пути через XLSX/ZIP сохранён; основания переходов и документов — функция шага 93.
- Подтверждение требует актуального оригинала того же процесса и редакции: проверяется SHA-256 и зафиксированная привязка к модели. Требуется причина ручной оценки смысла и условий. Текст источника не исполняется, наличие пути не объявляется доказательством смысла.
- Разрыв/неполная привязка блокируют подтверждение, но допускают замечание. Проверка маршрута ограничена 10000 элементами / 20000 стрелками.
- Подтверждение, замечание и отзыв сохраняют отдельные события с реальным профилем, временем, причиной, снимком пункта и ссылкой/метаданными оригинала. Автор из формы не подменяет профиль; неизвестный actorId в запросе отклоняется.
- Повтор того же решения идемпотентен. При двух конкурентных разных решениях по одному предшествующему событию одна запись проходит, другая получает 422.
- При изменении текста/модели прежнее решение становится устаревшим; старый fingerprint и оригинал отклоняются. Удалённый пункт не теряет журнал: API возвращает историю с пустой текущей записью. Из UI открываются существующие пункты, по известному ID удалённый журнал доступен через API.
- Черновые решения недоступны исполнителю; чтение действующей модели не выдаёт черновую историю.
- Повреждённый журнал не перезаписывается. Предел 1000 событий проверен без автоматического удаления. Дополнительный предел — 8 МБ на модель; запись через AtomicTextFile, с отменой до замены.
- В штатной ZIP-резервной копии проверено присутствие ReconciliationReviews. Каталог исключён из Git и учтён в безопасном сбросе демо; реальный сброс при тесте не запускался. В XLSX/ZIP самой модели решения не включаются.
- Живой браузер открывает страницу из реестра, записывает подтверждение по разделу 2 TRACE-001, отзывает и повторно открывает сохранённую историю. Ширина 360 не даёт переполнения страницы, снимок 1440 визуально просмотрен.

HTTP-прогон: 36 запросов-проверок. Сквозной браузер/API-прогон: 11 групп вместе с импортом, исполнением, планом и происхождением источника.

## Границы

Решение относится к конкретному снимку, не является электронной подписью, истиной по умолчанию или свидетельством физического исполнения. Доступность оригинала проверена при подтверждении; текущая доступность после него проверяется отдельно на странице материалов. Модель может измениться после записи — последующая загрузка перестанет считать прежнее решение актуальным. Это не общая транзакция со всеми редактированиями модели. Журнал не удаляется автоматически.
