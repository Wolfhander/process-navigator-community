# Приёмка защиты данных (81)

`BackupIntegrityChecks` создаёт отдельное временное хранилище: две копии с уникальными именами, проверка архива, изменение JSON, восстановление исходных байтов и проверка страховочной копии. Файлы незавершённых записей не попадают в архив.

Негативные сценарии: повреждение содержимого, дублирующее имя ZIP, несовпадение размера и выход пути за Data. Отказ не меняет исходный файл. Отмена атомарной записи сохраняет старые байты, обычная замена проходит, промежуточные файлы не остаются.

Резервирование не является снимком согласованной транзакции всех сервисов. Для точной копии прекратить запись; для восстановления прекратить работу и перезапустить сервер после операции. Замена пофайловая, лишние файлы не удаляются. Копия ограничена 20 000 файлов / 512 МБ для проверки восстановления.
