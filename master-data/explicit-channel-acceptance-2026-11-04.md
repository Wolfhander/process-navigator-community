# Приёмка привязок документа к каналу

- Два одноимённых выходных документа: без ID сопоставление неоднозначно; явный ID выбирает нужный; отсутствующий ID не откатывается к совпадению по имени. Входной канал не принимает выходную привязку.
- На изолированной мастер-копии временно добавляется бумажный канал с явным ID; контроль выгрузки в колонке K и обратного предварительного просмотра штатной книги. Для старой книги сохранённый ID удерживается по ID шага и канала; если совместимость нарушена, требуется явная правка новой книги.
- Матрица и CSV разделяют общие каналы этапа и каналы выбранного объекта; не смешивают направление и другой ID. Пара сторон остаётся кандидатом, а не фактом передачи.
