# Проверка читаемости схемы

Контрольные варианты в `processReadability.test.mjs` и `processInstructionPage.test.mjs`:

1. Шрифт и перенос: широкие и узкие символы одинаковой длины, слово без пробелов, переключение размеров и слишком узкий блок.
2. Подписи стрелок: общая точка разметки просмотра и диагностики, две пересекающиеся подписи, касание без наложения.
3. Навигация: кнопка передаёт точный ID стрелки, а не ID её источника.
4. Большой фонд: 1100 блоков и 2100 стрелок, достижение пределов остаётся видимым и не меняет модель.
5. Регрессия штатного контрольного фонда: рекомендации по длинному тексту и наложению блоков остаются видимыми.

Автоматические проверки используют заданную функцию измерения; они не являются визуальной приёмкой разных браузеров и размеров окна. Для такой приёмки открыть учебную схему и «Инструкция → Читаемость схемы», затем проверить подсказку и переход при разных масштабах. Локальная модель не запускалась: использованы воспроизводимые проверки геометрии и компонентов.
