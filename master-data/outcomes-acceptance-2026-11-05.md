# Исходы выполнения — приёмка пункта 97

Учебные данные считаются согласованным мастер-контуром. Проверки: ExecutionOutcomeChecks.cs (параллельная модель start → a → AND b/c → d → end), executionOutcome.test.mjs и outcomes-этап verify-core-flow-browser.mjs. Все файлы/экземпляры создаются в изолированной временной установке; рабочие данные не изменяются.

Критерии: успех после применимых действий; отказ, ошибка и отмена требуют причины; сохраняются время, профиль, точный набор незавершённых действий и ранее записанные результаты/метаданные вложений. Закрытие не превращает эти действия в выполненные или пропущенные. Повторное открытие читает сохранённый исход; дальнейшее изменение/возобновление запрещено. Два конкурентных закрытия дают один результат. Противоречивый исход в хранилище отклоняется.

Сервер: 836 сценариев общего прогона, включая 37 новых проверок. Проверяется реальный XML с errorEventDefinition и запрет запуска специальных конечных событий. Клиент отдельно проверяет классификацию, старые записи, безопасный вывод и CSV; живой браузер — запись ошибки, сохранённый промежуточный результат и повторное открытие.

Ограничения: отказ/ошибка фиксируются человеком, а не автоматически получаются из внешней системы. Неуспех использует совместимый статус Cancelled плюс отдельный Outcome. Старые Completed/Cancelled без Outcome не ретроклассифицируются. Останавливаются действия данного экземпляра, не независимые дочерние экземпляры. Полная семантика специальных BPMN-событий, таймеров и сообщений относится к пункту 96; такие конечные события видны, но запуск и табличное изменение с потерей семантики заблокированы. Это не универсальный BPMN-движок.

Изолированная проверка обнаружила также старую проблему последовательного импорта после публикации первой модели: файл __missing__.bpmn ошибочно воспринимался как наличие любого нового ID. В .118-dev дефект исправлен и принят отдельно: process-identity-acceptance-2026-11-05.md. Браузерный сценарий теперь импортирует и публикует вторую модель штатным API, без прямого создания опубликованного файла.
