# Приёмка шага 79: клавиатура, фокус, подписи

Дата: 2026-11-05. Контур синтетический, рабочих данных и API-записей нет.

## Воспроизведение

Из frontend/process-navigator-ui выполните:

```powershell
node --test tests/accessibility.test.mjs
node tests/renderAccessibilityFixture.mjs ../../artifacts/keyboard-accessibility-final.html
```

Генератор не перезаписывает файл: для нового прогона выберите новое имя.
Из корня репозитория (установленный Microsoft Edge, Node с WebSocket):

```powershell
node tools/verify-keyboard-browser.mjs artifacts/keyboard-accessibility-final.html
```

Инструмент создаёт собственный скрытый Edge с отдельным профилем, динамическим отладочным портом и закрывает только его. Подключения к существующему браузеру нет. Профили и снимок остаются в игнорируемой artifacts.

## Проверенные результаты

1. Настоящие CDP-события Tab/Shift+Tab/Enter/Space: переход к main, доступное имя этапа, отдельная кнопка детализации.
2. Пробел на SVG не прокручивает страницу, удержание клавиши не повторяет действие (модульная проверка).
3. Фокус в модальном поиске: начало/конец Tab-цикла. Вложенный alertdialog возвращает фокус на кнопку подтверждения; закрытие поиска — на исходную кнопку.
4. Пустой модальный диалог удерживает фокус. Ранее установленный inert не снимается контроллером; контроллер не присваивает себе управление чужим inert.
5. Контрольная страница: CSS-масштаб 200% при viewport 1280, без горизонтального переполнения; снимок keyboard-accessibility-200.png визуально просмотрен. Это CSS-эквивалент увеличения содержимого, не автоматизация меню масштаба браузера.
6. prefers-reduced-motion: reduce меняет длительность переходов. Контраст базовых пар обычного текста/подложки и фокуса >= 4.5:1 рассчитан тестом; высококонтрастный режим имеет системный цвет Highlight.

SVG-разметка взята из настоящего NodeShape, CSS и контроллер — из исходников приложения. Диалоги на стенде синтетические: проверяется общий контроллер, а не живой поиск/API. Не заявляется полный обход всех страниц, аудит каждого пикселя, сертификация WCAG или проверка всех скринридеров. Сторонний BPMN-редактор имеет собственное управление. Доступ к функциям по-прежнему определяется правами сервера.
